# Язык True — спецификация

Версия языка: **0.10.0**  
Версия интерпретатора: **1.2.0**  
Лицензия: Apache 2.0 (`LICENSE-TRUE`)

## Терминология

- **Контейнер** — строка данных. Всё в языке — контейнеры.
- **Именованный контейнер** — контейнер с именем (`value = name`).
- **Цикл (cycle)** — файл `.cycle` (файл-функция).
- **Агент (agent)** — файл `.agent` (файл-функция + UI-кнопки агента).
- **`.true`** — больше не используется (зарезервировано для настроек проекта).

## Принципы

1. **Всё — контейнер.** Нет чисел, типов, массивов. Только контейнеры и соглашения о них. **Кавычки — часть контейнера**, не синтаксис. `"Hello"` — контейнер `"Hello"` (7 символов, с кавычками). `Hello` — контейнер `Hello` (5 символов, без кавычек). **Пустой контейнер — 0 символов.** Литерал `""` — 2 символа (`"` и `"`), не пустой контейнер. Чтобы получить пустой контейнер, используйте `= name` или отсутствие результата.
2. **Программа — база данных.** Данные хранятся в тексте файла. Изменение значения по имени меняет и текст объявления.
3. **Сначала данные, потом действия.** `data, args => :op`.
4. **`=>` копирует, `->` перемещает.** `->` стирает значение в источнике, имя остаётся.
5. **Оси `l/x/y/z`** — единственный способ структурировать контейнер. Ось по умолчанию — `x`.
6. **Контейнер — многомерный массив** данных (`l`, `x`, `y`, `z`). Многомерность — через вложенные оси.
7. **Никаких новых типов** (`map`, `stack`, `queue`, `tree`, `graph`, указателей).
8. **Никаких `for/while`.** Только неявный цикл программы + переходы `^` и условия `?`.
9. **Код должен быть наглядным**, чтобы много не додумывать (меньше тратить сил, меньше делать ошибок, писать более качественный код более быстро).
10. **Имя справа.** `0 = a` — данные слева, имя справа.
11. **`@` — константа, `*` — скрыть.**
12. **Программа — это switch.** Каждая строка — ветка switch.
13. **Программа всегда исполняется агентами.** 1 агент на `.agent`-файл. Каждый агент виден одновременно (`Cycles`, `FileChips`, `Log`).
14. **`-> nothing` — универсальный сток.** `file:x -> nothing`, `<var> -> nothing`. Каскад: файл → агент. Фиолетовая подсветка — знак необратимости.
15. **Работаем с тем, что есть.** У данных всегда есть адрес — номер строки. Имя — дополнительная ссылка. Если имя есть — по имени. Если нет — по адресу (`^ N`). Имя появляется в момент именования (`данные = имя`) и живёт, пока данные существуют.
16. **Всё — функция с `:`.** Системные имена зарезервированы. Пользовательский файл `name.cycle` / `name.agent` — функция `:name`.
17. **`:result` хранит, не возвращает.** Кто-то заберёт, а может и нет. Waiter — авто по наличию `:result` в файле.
18. **Запись/чтение — симметрично** (кроме `@`-констант).
19. **`actions` — программа агента.** Многострочная, по умолчанию `":run"`. `:run` — атомарное выполнение. `:run` без аргумента — выполняет текущую строку.
20. **Контейнеры агента:** `step` (номер строки), `cycle` (имя файла).
21. **`:error` — стек ошибок файла.** `:error`, `:error:line`, `:error:message`, `:error:lines`, `:error:messages`. Реакция — `actions`: `":error ? ^ :handle"`. `:error` не отменяет `PAUSED`.

## Файлы

| Расширение | Тип | UI | Агент |
|---|---|---|---|
| `.cycle` | Цикл (файл-функция) | Кнопки файла | Нет |
| `.agent` | Агент | Кнопки файла + кнопки агента | Да |
| `.txt`, `.json`, без расширения | Файл | Кнопки файла | Нет (но агент может ходить) |
| `.true` | **Не используется** (настройки проекта) | — | — |

**Любое расширение** — агент может ходить по любому файлу через `^ file.ext`.

## Программа

- Нумерация строк с 1.
- Программа по умолчанию — цикл: после последней строки без `=> :stop` исполнение возвращается на первую.
- `\` в начале строки — вся строка воспринимается как текст.
- `\` перед символом операции (`=`, `=>`, `^`, `->`, `?`, `->|`, `=>|`) — символ воспринимается как текст; `\` в выводе отбрасывается.
- Строка без распознанной операции — комментарий.
- **Примеры в `SAMPLES.md`** — работают **в середине цикла**. Завершение (`=> :stop`) — отдельный вопрос.

## Именование

```true
value = name
value = name *
value = name @
```

- `name` — идентификатор `[A-Za-z_]\w*`. `nothing` — зарезервировано.
- `*` — скрыть из основного списка Values.
- `@` — константа: запись и перемещение запрещены.
- **Действие:** если `value` содержит `=>`/`->`/`^`/`?` — это **действие** (не подставляется, сохраняется как текст). `a + 1 => a = action` — `action` = `"a + 1 => a"`.

Изменение значения по имени меняет текст программы в месте объявления (`syncCodeWithVariables`). Константы (`@`) не переписываются.

### Имя до использования

**Правило:** прежде чем использовать имя — оно должно быть присвоено.
`= name` (пустой контейнер) или `value = name`.

**Исключение:** если имя — **уже** переменная (присвоено ранее) — `= name` не нужно. Например, `lineCount` после `raw:l => :size => lineCount` — уже переменная, `lineCount = result` — **избыточно**.

**Цепочки:** `a => :f => dst` — `dst` **должен** быть присвоен до. Иначе — литерал `dst`.

```true
= result
1, 2, 3 => :sum => result   \ result = "6"
```

**Без `= result`:**

```true
1, 2, 3 => :sum => result   \ result — литерал "result"
```

### Принцип «работаем с тем, что есть»

У данных всегда есть **адрес** — номер строки. **Имя** — дополнительная ссылка.

**Пример — имя есть:**

```true
0 = lineCount
input.txt => :file:data
= empty
empty$:file = raw
raw:l => :data:size
:size = lineCount
lineCount => out
```

**Пример — имени нет, обращение по адресу:**

```true
^ 5
=> :stop
```

**Если имя не создано:** обращение по имени вернёт литерал (текст). Обращение по адресу (`^ N`) — работает всегда.

## Метки и переходы

```true
= label
^ N
^ label
^ file_name.cycle
^ file_name.agent
^ data.txt
^ :stop
^ :pause
^ :resume
^ :delete
^ :reset
```

- `= label` — именование пустого контейнера (метка).
- `^ N` — go-to по номеру строки (N — число).
- `^ label` — go-to по метке (без точки, есть в текущем файле).
- `^ file_name.cycle` / `^ file_name.agent` / `^ data.txt` — go-to на файл (есть точка — расширение).
- `^ :stop` / `^ :pause` / `^ :resume` / `^ :delete` — команды агенту (как UI-кнопки).
- `^ :reset` — сброс файла (как `⟲`).
- `^ notes` (без точки, нет метки, не число) — **ошибка**.

**Приоритет разбора `^`:**
1. Число → строка N.
2. `:stop` / `:pause` / `:resume` / `:delete` / `:reset` → команда.
3. Метка (без точки, есть в файле) → метка.
4. Файл (есть точка) → файл.
5. Иначе → ошибка.

**Файл — только с точкой (расширение).** Без точки — метка (если есть) или число.

## Условия

```true
условие ? операция
```

- Слева от `?` — условие; справа — любая операция.
- Поддерживаются `==`, `!=`, `<`, `>`, `<=`, `>=`, `&&`, `||`, `!`.
- **Скобки поддерживаются:** `(a == 1 || b == 1) && c == 2`.
- **Приоритеты:** `||` < `&&` < `!` < сравнение.
- Сравнение: числовое, если обе стороны — числа; иначе — лексикографическое.
- Если справа от `?` нет операции — `?` остаётся текстом.
- В строке — ровно один `?`.

**Примеры:**

```true
a < max ? ^ do
(a == 1 || b == 1) && c == 2 ? 5 = d
!(a == 1) ? 9 = e
```

## Копирование и перемещение

- `a => b` — копирование.
- `a -> b` — перемещение.
- `v -> data:y:3` — **замена** элемента.
- `v ->| data:y:3` — **вставка** (перемещением).
- `v =>| data:y:3` — **вставка** (копированием).
- `file:a => file:b` — копия содержимого файла. `file:a -> file:b` — перемещение. Полные пути.
- `file:a => var` — чтение файла в контейнер. `var => file:b` — запись контейнера в файл.

### Цепочки `=>`

`=>` можно **сцеплять**: `data => :fn1 => :fn2 => dst`. Результат каждой функции — вход следующей. **Промежуточные именования не нужны.**

```true
input.txt => :get => raw
raw:l => :size => lineCount
1, 2, 3 => :sum => result
```

## Команды

```true
=> :pause
=> :resume
=> :stop
=> :reset
=> :activeTab
=> :activeTab, step
```

- `:pause` / `:resume` / `:stop` — статус текущего агента.
- `:reset` — обычный шаг.
- `:activeTab` — переключить вкладку.
- **`:stop` ≠ `break`.** `:stop` завершает **программу**, не цикл. Для выхода из цикла — `^ label` за пределы.

## `:math` — числовые операции

| Операция | Синтаксис |
|---|---|
| Арифметика | `a + b => :math` |
| Битовые | `a & b => :math`, `a << 1 => :math` |
| Функции | `abs(a) => :math`, `popcount(a) => :math` |
| Булевы | `a == b => :math` → `0/1` |
| Списки | `1, 2, 3 => :math:sum`, `:math:min/max/avg/product/count/sort` |

**Булевы операторы** — с приоритетами и скобками. Сравнения — после арифметики: `1 + 2 == 3 => :math` → `1`.

**Результат:** `results["math"]`, `results["math:op"]`. В `variables` — через `:math => var` или `:math:sum = sum` / `:math:sum => sum`. Если результата нет — пустой контейнер.

## `:data` — операции над контейнером

| Операция | Синтаксис | Ось |
|---|---|---|
| `substring` | `data, start, end => :data:substring` | только `x` |
| `indexOf` | `data, sub => :data:indexOf` | по оси |
| `replace` | `data, old, new => :data:replace` | только `x` |
| `lower` / `upper` / `trim` | `data => :data:lower` | по оси |
| `chars` | `data, sep => :data:chars` | только `x` |
| `charAt` | `data, i => :data:charAt` | по оси |
| `size` | `data => :data:size`, `data:y => :data:size` | по оси |
| `:s` | `data => :s`, `data:y => :s` | по оси (кратко) |
| `reverse` / `unique` | `data => :data:reverse` | по оси |
| `contains` | `data, v => :data:contains` | по оси |
| `slice` | `data, from, to => :data:slice` | по оси |
| `join` | `data, axis => :data:join` | по оси |
| `sort` | `data:y => :data:sort` | по оси |
| `push` | `data:y, v => :data:push` | по оси |
| `pop` | `data:y => :data:pop` | по оси (стек: `pop` — вершина, `pop_rest` — остаток) |
| `remove` / `swap` | `data:y, ... => :data:<op>` | по оси |
| `deleteRange` / `replaceRange` | `data:y, from, to => :data:<op>` | по оси |
| `filter` | `data, cond => :filter` | по `y` |
| `matches` | `data, regex => :matches` | по `x` |

**Удалены (deprecated):** `:data:insert` (→ `->|`), `:data:set` (→ `->`), `:data:length` (→ `:data:y:size` / `:s`).

**Ось явная или по умолчанию `x`.** Исключение: `substring`, `replace`, `chars` — только `x`.

### Префикс `:data` / `:math` необязателен

Если операция **не конфликтует** с другой — префикс можно опустить:

```true
1, 2, 3 => :sum        \ то же, что :math:sum
arr:y => :pop          \ то же, что :data:pop
arr:y => :size         \ то же, что :data:size
arr:y => :s            \ кратко :data:size
arr:y => :sort         \ то же, что :data:sort (строки)
```

**Обязательный префикс:**
- `:math:sort` — сортировка **чисел** (`:sort` — строки).
- `:json:*`, `:file:*`, `:api:*` — группы.

### `<name>:splitter` — сплиттеры для осей любой строки

```true
. => raw:splitter:l:;
```

- `<name>` — имя переменной (`raw`, `csv`, `line`), не `data`.
- `<axis>` — `l`, `x`, `y`, `z`.
- `<sep>` — разделитель (строка, без пробелов).

**По умолчанию:** `l` — `\n`, `x` — пусто, `y` — `,`, `z` — `;`.

|---|---|
| `file:data` | `path => :file:data` / `path, content => :file:data` |
| `file:origin` | `path => :file:origin` / `path, content => :file:origin` |

## `:error` — стек ошибок файла

Ошибки — **на уровне файла**, не агента. Стек накапливается.

| Функция | Результат |
|---|---|
| `:error` | `"1"` / `"0"` — есть ли ошибки |
| `:error:line` | номер последней строки |
| `:error:message` | последнее сообщение |
| `:error:lines` | все строки через `,` |
| `:error:messages` | все сообщения через `\n` |
| `:error => dst` | в `dst` |
| `:error:lines => dst` | в `dst` |

**Реакция — через `actions`:**

```
:error ? ^ :handle
:run
```

**Сброс:** `reset()` — очищает стек.

## `foreach`

```true
data:foreach:axis1, axis2 ; var1, var2 :
instruction1,
instruction2,
last_instruction
```

- Несколько осей — вложенные циклы (до 3).
- **Конец тела — отсутствие `,` в конце строки.**
- **`.` больше не нужен.**
- Вложенный `foreach` запрещён — `errorLine`.
- Ошибка в теле прерывает `foreach`.
- `changed` содержит переменные осей и `result`.

## Функции — файлы

**Файл = функция.** `math.cycle` — функция `:math`.

```true
math:fact:
parameters == 0 ? 1 => :result
parameters - 1 => .:math:fact => sub
parameters * sub => :math => :result
:result
```

- `:parameters` — маркер входа.
- `=> :result` — установка значения. **Не возвращает**, хранит.
- `:result` в конце — маркер конца. Waiter — авто.
- `:run` — атомарное выполнение.
- `:log` — залогировать.

Вызов: `data => :math`, `data => :main`.

**Системные имена зарезервированы.**

## `actions` — программа агента

- `AgentState.actions: String` (многострочная), по умолчанию `":run"`.
- `executeOneStep` двигает `currentStep`, выполняет `actions`.
- `:run` — атомарное выполнение (без `actions`, без рекурсии).
- `:log` — логирует текущую строку.
- Если `:run` нет — строка не выполняется (только `actions`).

## Агенты

Программа **всегда** исполняется агентами. 1 агент на `.agent`-файл. Несколько `.agent` — несколько агентов.

### Контейнеры агента

| Контейнер | Что |
|---|---|
| `step` | Номер строки (обновляется при движении) |
| `cycle` | Имя файла (обновляется при перемещении) |

### Функции агента (с `:`)

```true
:agent:<name>:status      => <dst>
:agent:<name>:waiter      => <dst>
:agent:status             => <dst>
```

### Управление агентом

```true
^ :stop
^ :pause
^ :resume
^ :delete
^ :reset
```

### Пауза себя

```true
<ms> => :agent:wait
```

### Waiter — автоопределение

- `:result` в файле → waiter. После `:result` — снова ждёт `parameters`.
- Нет `:result` → циклический.

### Вертикальные файлы

- `fileOrder` — порядок по вертикали (ось Y).
- Кнопки `↑` / `↓` в линии кнопок файла.
- Порядок движения агентов — по Y (сверху вниз).

### UI

**Кнопки файла** (`⟲`, `↑`, `↓`, `✎`, `🗑`) — сверху, **для всех** файлов.
**Кнопки агента** (`▶⏸⏹⏭⏮`) — снизу, **только** для `.agent`.
**`⛶`** — в header, для всех.

**`⋯` удалён.** `Templates…`, `Actions…`, `Copy to…`, `Move to…`, `Delete agent` — **удалены**.

## Ошибки

- **Валидация:** неизвестная метка, `Multiple ?`, `=> :result inside function`.
- **Strict Mode:** запрет `:` функций; разрешены `:parameters`, `:result`, оси, `:status`, `:wait`, `:nothing`, `:run`, `:log`, `:message`, `:s`, `:range`, `:repeat`, `:save`, `:error`, `:agent`, `:splitter`, `:foreach`, `:filter`, `:matches`, `:json`, `:file`, `:api`, `:console`, `:load`, `:get`, `:post`, `:path`, `:activeTab`, `:source`, `:test`, `:return`.
- **Выполнение:** запись в константу, выход за диапазон, файла нет → `PAUSED` + `errorLine`.
- **Агенты:** `occupied` → `error` (`PAUSED`).
- `nothing = ...` → `error: 'nothing' is reserved`.
